# Editorial image inventory

This inventory is the approval record for public editorial photography. Only
`APPROVED_FOR_USE` assets are bundled under `static/images/editorial/`. Every
local variant is a compressed JPEG derivative; no original file is served. The
textile variant is a reviewed detail crop; the house and mountain variants are
resized. Responsive presentation also uses CSS `object-fit: cover`, with every
adaptation identified in the visible attribution/source detail.

## Attribution delivery

Hero credits visibly show `Photo: [author] / Wikimedia Commons` plus `CC BY-SA
4.0`, and link to the Commons file page. Gallery captions retain the source
title, licence link, and adaptation note. The textile derivative is a reviewed
centre detail crop (no faces or attribution elements in the source image were
removed); the other derivatives are resized. The underlying licence requires
attribution, a licence link, and an indication of the responsive conversion /
crop; it does not imply photographer endorsement.

## Remaining review boundaries

- Do not use colonial-era Tagabawa portraits or broader Bagobo event imagery as
  current Bagobo-Tagabawa editorial photography without explicit community
  review.
- The Culture textile photo is approved for its source-described factual
  context. Any interpretation of symbolism, ritual use, or cultural meaning
  beyond that caption remains `IMAGE RIGHTS: NEEDS REVIEW` for editorial and
  community review.
